# Agent instructions

If you can read the private repo `paul-lapczynski/rhythm-agent`, start with
its `AGENTS.md`. Otherwise read [CONTINUE.md](CONTINUE.md) before doing anything: it has the current
state, the next tasks in order, how to build and release, and the hard rules
(no pushes to `main`, PRs only, never commit songs, audio, artwork or
commercial or fan charts, never commit `training-data/`, and the charting rules for Expert and lower difficulties).
